# Genvis AI 前端界面展示建议

本页用于规范 GitHub、官网文档、社群推广中可以公开展示的前端界面。展示目标是让访客理解 Genvis AI 的使用体验和产品能力，引导注册试用；不是公开完整产品源码或内部运营系统。

## 推荐展示的界面

### 1. 官网首页与能力入口

可以展示官网首屏、模型能力入口、注册入口和控制台入口，让访客快速知道 Genvis AI 支持文本、图片、视频能力。

建议突出：

- 新用户注册即享 2 美元免费试用额度
- 支持 Claude4.8、GPT5.5、Gemini3.5 等文本推理模型
- 支持 gpt-Image2、Nano Banao 2 等图像生成模型
- 支持 Veo、sora2、GrokVideo 等视频生成模型
- 官网入口：[https://genvis.xyz](https://genvis.xyz)

### 2. 可视化生图界面

可以展示生图页面的模型选择、提示词输入、尺寸比例、风格参数、批量生成和结果预览区域。

适合展示的功能点：

- 无需代码，可视化参数调节
- 高清图像生成
- 风格自定义
- 批量出图
- 商品图、广告图、封面图、社媒图等示例效果

截图建议：

- 使用演示账号或空白账号
- 只展示公开模型名和普通示例提示词
- 生成结果可以使用样例素材，不展示客户真实项目图
- 余额、订单、用户 ID、API Key 等敏感区域需要打码或裁掉

### 3. 可视化生视频界面

可以展示视频生成页面的文生视频、图生视频、时长、比例、清晰度、任务进度和视频预览区域。

适合展示的功能点：

- 文生视频
- 图生视频
- 长短视频渲染
- 异步任务进度
- 影视级画面效果和流畅动态输出

截图建议：

- 只使用可公开传播的演示图片和提示词
- 不展示内部任务 ID、供应商返回字段、成本字段和调度信息
- 不展示真实客户素材、未授权人物图片或商业订单内容

### 4. API 接入与模型列表界面

可以展示控制台中经过打码的 API Key 创建入口、模型列表入口和公开文档入口，帮助开发者理解接入路径。

适合展示的功能点：

- 创建 API Key
- 查询可用模型
- 查看 API Base URL
- 复制 Node.js、Python、cURL 示例

必须隐藏：

- 完整 API Key
- 真实用户邮箱、手机号、头像、用户 ID
- 真实余额、充值记录、订单号、发票信息
- 内部渠道、供应商账号、成本价、路由策略

## 不建议公开的内容

- 后端源码、数据库结构、模型路由和供应商适配逻辑
- 计费、风控、权限、管理后台、运营后台完整界面
- 生产环境变量、部署配置、日志、监控面板
- 真实用户数据、订单数据、API 调用记录和成本报表
- 未发布的新功能、内部模型策略、商业定价底层逻辑

## 对外展示文案口径

推荐说法：

```text
本仓库用于展示 Genvis AI 的部分前端体验和公开 API 接入方式，帮助开发者快速了解文本、图片、视频生成能力。完整产品能力请前往官网注册试用。
```

避免说法：

```text
完整开源 Genvis AI 平台源码。
```

```text
公开全部模型路由、计费和后台实现。
```

## 推荐转化链路

1. GitHub README 让访客看到能力、价格示例和 2 美元试用福利。
2. 前端界面截图展示可视化生图、生视频体验。
3. Quickstart 文档提供最小 API 调用样例。
4. 引导访客进入 [Genvis AI 官网](https://genvis.xyz) 注册试用。
5. 有开发需求的用户再使用本仓库示例接入自己的业务系统。
