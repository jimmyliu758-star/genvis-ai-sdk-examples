# 错误码与排查

接口调用失败时，先按本页顺序排查。反馈问题时不要提供完整 API Key。

## 401 Unauthorized

表示认证失败。

常见原因：

- API Key 写错
- Header 中缺少 `Bearer`
- 令牌已删除
- 令牌已过期

正确写法：

```http
Authorization: Bearer YOUR_API_KEY
```

## 403 Forbidden

表示身份有效，但没有权限。

常见原因：

- 当前模型未对用户组开放
- 令牌限制了模型
- 账号余额或试用额度不足
- 组织、团队或控制台权限限制了访问

## 429 Too Many Requests

表示触发限流。

处理方式：

- 降低并发
- 增加重试间隔
- 使用异步队列处理图片和视频任务
- 更换可用模型或稍后重试
- 联系平台确认限流策略

## 余额或额度不足

常见原因：

- 免费试用额度已用完
- 钱包余额不足
- 令牌额度限制过低
- 当前模型、尺寸、时长或质量档位价格高于可用额度

## 模型不存在或不可用

先请求模型列表：

```bash
curl "$GENVIS_BASE_URL/models" \
  -H "Authorization: Bearer $GENVIS_API_KEY"
```

然后使用返回列表中的模型 ID。

## 视频没有立即返回结果

视频生成通常是异步任务。提交后保存任务 ID，再轮询任务详情接口直到状态变为完成或失败。

## 仍然无法解决

请保留以下信息再反馈：

- 请求地址
- 请求时间
- 模型 ID
- 返回错误信息
- 令牌名称

不要提供完整 API Key、真实用户数据、内部订单信息或未打码截图。
