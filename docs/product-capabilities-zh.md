## 全量支持旗舰 AI 模型

Genvis AI 聚合文本推理、图像生成和视频生成模型，帮助团队用一个账号、一个 API Key、统一接口完成多模态内容生产。

| 能力 | 旗舰模型示例 | 可以完成的任务 |
| --- | --- | --- |
| 文本推理 | Claude4.8、GPT5.5、Gemini3.5 等 | 智能问答、内容创作、代码辅助、知识库问答、Agent 推理、工作流编排 |
| 图像生成 | gpt-Image2、Nano Banao 2 等 | 文生图、参考图生成、商品图、广告图、海报封面、角色图、视觉创意 |

模型权限、价格和可用状态可能随账号、用户组和平台策略变化，接入前建议在控制台或 `/v1/models` 接口确认最新可用模型。

- 返回结构化素材，便于入库、展示、下载、审核和后续自动化处理

典型场景：

- AI 工具站统一模型网关
- Dify、Coze、n8n、FastGPT 等工作流接入
- 电商批量生成商品图、详情图、广告图
- 自媒体批量生成封面、配图和短视频素材
- 企业内部内容中台、素材库和创意自动化系统

## 从试用到接入的推荐路径

1. 打开 [Genvis AI 官网](https://genvis.xyz) 注册账号，领取 2 美元免费试用额度。
2. 在可视化界面体验图像生成和视频生成，确认模型效果、提示词和参数。
3. 在控制台创建 API Key，并用 `/v1/models` 查询当前账号可用模型。
4. 克隆本仓库，运行 Node.js、Python 或 cURL 示例。
5. 把稳定提示词、模型 ID、尺寸、时长、风格参数接入自己的产品或工作流。
6. 需要放量时通过微信或支付宝充值，并按业务场景拆分 API Key 和任务队列。

## 开发者集成建议

- 图片和视频生成建议使用异步任务队列，避免用户请求长时间阻塞。
- 视频任务提交后保存任务 ID，前端通过轮询或后端回查更新状态。
- 将模型 ID、尺寸、质量、视频时长等参数做成后台配置，便于运营调优。
- 对生成结果建立素材表，保存原始提示词、模型、参数、成本、URL 和审核状态。
- 不要把 API Key 暴露在前端页面、浏览器脚本、移动端 App 或公开仓库中。
